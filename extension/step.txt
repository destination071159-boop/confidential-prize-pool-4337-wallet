================================================================================

PART 4 — THE BLIND DRAW (1:45 – 2:30)   [~45s]   *** owner account only ***
================================================================================

STEP F — DRAW
  DO:  scroll to "3 · Draw" → click  "🎲 Trigger confidential draw"
  SAY: "Now the draw. This calls FHE.randEuint64 — the randomness is generated

  WAIT for ✅.

  DO:  under "Your winnings" click  "Reveal (decrypt)"
  SAY: "I decrypt my winnings — and only the actual winner sees a non-zero prize.

QUICK REFERENCE — THE CYCLE (for on-screen captions if you add them)
================================================================================
  Faucet  →  Deposit (encrypted)  →  Enable view  →  Reveal balance
          →  Draw (FHE-random, weighted)  →  Reveal + Claim  →  Withdraw (no-loss)

WHAT'S ENCRYPTED : deposit amount, balance, pooled total, each player's odds, the winner
WHAT'S PUBLIC    : the set of depositors, the count, and timing (deliberate, documented)

GOTCHAS / IF SOMETHING STALLS:
  - First decrypt is slow (relayer warming up) — that's why you did a practice run.
  - "Enable private view" must be done once per account before Reveal works.
  - Draw disabled/greyed out = you're not on the owner account.
  - If a button does nothing, check the paymaster/bundler env is set (VITE_BUNDLER_URL).
  - Re-run a full practice cycle right before recording so balances are in a clean state.
